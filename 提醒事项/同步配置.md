# iCloud 提醒事项 同步配置

`sync.py` 通过 iCloud CalDAV 直接把提醒写进你苹果设备的「提醒事项 App」，跨设备同步，**不需要 Mac 开机**。

## 一次性配置（约 2 分钟）

### 1. 生成 App 专用密码
1. 打开 [appleid.apple.com](https://appleid.apple.com) → 登录
2. **登录与安全** → **App 专用密码** → 生成新密码
3. 复制那串密码（形如 `abcd-efgh-ijkl-mnop`）

> 用 App 专用密码而非主密码：更安全、可单独吊销，且账号开了双重认证时 CalDAV 必须用它。

### 2. 把凭据放进环境变量

在 **Claude Code 远程环境配置**里加两个环境变量（不要写进仓库/代码）：

| 变量 | 值 |
|---|---|
| `ICLOUD_USERNAME` | 你的 Apple ID 邮箱 |
| `ICLOUD_APP_PASSWORD` | 上一步的 App 专用密码 |
| `REMINDER_TZ` | `Asia/Shanghai`（可选，默认就是它）|

> 配置位置见：https://code.claude.com/docs/en/claude-code-on-the-web（环境变量 / setup）。
> 本地用也可以临时 `export ICLOUD_USERNAME=... ICLOUD_APP_PASSWORD=...`。

### 2.5 网络出口白名单（远程环境必做）
iCloud 的提醒数据不在 `caldav.icloud.com`，而在**按账号分区的主机**上
（形如 `p133-caldav.icloud.com`）。只放行 `caldav.icloud.com` / `*.caldav.icloud.com`
**不够**——`*.caldav.icloud.com` 匹配不到 `p133-caldav.icloud.com`（连字符≠点）。
请在网络出口设置里加上（任选其一）：

| 白名单条目 | 说明 |
|---|---|
| `caldav.icloud.com` | 发现/登录入口（已加） |
| `*.icloud.com` | **推荐**：覆盖所有分区主机（`pNN-caldav.icloud.com`）。注意不能用 `*-caldav.icloud.com`——通配符只能替换整段子域标签，标签中间带 `*` 的写法非法、存不进去 |
| `p133-caldav.icloud.com` | 本账号当前分区主机（最小授权，iCloud 偶尔换分区会失效） |

> 白名单改动**只对新会话生效**，改完需重开新会话验证。

### 3. 装依赖（环境首次）
```bash
pip install caldav icalendar
```

## 验证

```bash
python3 提醒事项/sync.py lists        # 列出你的提醒事项列表，能列出即打通
```

## 日常用法（我会替你跑）

```bash
# 新增提醒
python3 提醒事项/sync.py add \
  --title "孙建亚老师 家前采时间确认（绿洲比华利花园931号楼）" \
  --list "工作-采访" --due "2026-07-02 10:00" --alarm "2026-07-02 09:00"

# 查看某列表
python3 提醒事项/sync.py show --list "工作-采访"
```

打通后，你在本 group 粘进来的每条文字，我会解析后**直接**调用 `sync.py` 写进你的 iCloud 提醒事项，并在 `日程.md` 留一份登记。

## 安全说明
- 凭据只存在于环境变量，**不进仓库、不进代码、不进 commit**。
- App 专用密码可随时在 appleid.apple.com 吊销，不影响主密码。
