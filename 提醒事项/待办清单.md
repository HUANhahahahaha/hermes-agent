>    `estimated_cost_usd` 传两次（照 `actual_cost_usd` 的写法）。

`n/a` 而不是谎称花了 0 元。这个 bug 已经骗了用户一个月。

### 🔍 第三个根因已找到（2026-08-03，在仓库里静态排查得出，无需服务器）

**结论：前两处修复根本影响不到日报的数字。** 日报不读数据库里存的
`estimated_cost_usd` —— `agent/insights.py:41` 的 `_estimate_cost()` 是拿会话行里的
**model + token 列 + billing_provider** 在出报表时**当场重算**的。所以
`hermes_state.py` 那两行 `COALESCE` 只影响「存进去的值」，不影响「报出来的值」。

**真正让它报 0 的是这条**：`resolve_billing_route()`（`agent/usage_pricing.py`）
在 `provider` 为空时把路由判成 `unknown`，而官方价格表的键是
`(provider, model)` —— **表压根不会被查**。而 `provider` 是可选参数
（`agent_init.py` 里 `provider: str = None`，注释写「用于遥测/路由提示」），
只配 API key + 模型名的部署就是空的。

于是：**价格表补得再全也没用，每一条会话都算成 unknown → 报表显示 0。**
这解释了 Clawbot 说的「主要修复上次已包含，日报却还是 0」那个逻辑缺口。

已复现（打补丁前）：
```
provider=None  model='claude-sonnet-5'  → route.provider='unknown'  status=unknown  amount=None
provider='anthropic' 同一模型          → route.provider='anthropic' status=estimated amount=0.150
```

**修复**：`provider` 为空时按模型名前缀推断厂商（`claude-*`→anthropic、
`gpt-*`/`o3`→openai、`gemini-*`→google、`deepseek-*`、`anthropic.*`→bedrock）。
显式配了 `custom`/`local`/localhost 的**不覆盖**（自建端点的价格是人家自己的，
猜一个数字比承认不知道更糟）；认不出的模型仍然报 `unknown` 而不是 0。
新增 4 个测试，`test_usage_pricing.py` 15 passed、`test_hermes_state.py` 与
`test_insights.py` 全绿。

**服务器上一条命令就能验证是不是这个原因**（在 VPS 上跑，只读）：
```
grep "API call #" ~/.hermes/logs/agent.log | tail -20
```
输出里是 `provider=unknown` → 就是它。是 `provider=anthropic` → 那还有第四个根因。

### ⚠️ 重启后若日报仍为 0，说明还有第三个根因

Clawbot 报告称：**Claude 5 定价条目与 `hermes_state.py` 的 CASE WHEN 写法
「上次改动已包含」**，即这两处主要修复此前就已在生产环境。本次真正新增的
只有 Gemini 3.x 条目 —— 而机器人跑的是 **Sonnet 5，不是 Gemini**。

于是存在逻辑缺口：**若主要修复早已在生产，日报为何仍报 0？**

- 可能 A：改了但一直没重启 → 本次重启即可解决
- 可能 B：**还有第三个根因未找到** → 重启后仍为 0

**因此重启后必须实测验证**，不要默认已修好。验证方式：查最近会话的
`estimated_cost_usd` 与 `cost_status` —— 有数字且状态为 `estimated` 才算成功；
若仍是 0 或 `unknown`，那是新线索，需回头排查日报汇总逻辑本身、
或 token 用量是否根本没写进库。

**改了什么**（三处，缺一仍会报 0）：
1. 定价表补齐整个 Claude 5 系列（机器人跑 Sonnet 5，此前表里没有）
2. `COALESCE(?, 0)` → `CASE WHEN ? IS NULL`：未知不再被伪装成 0 元
3. 模型名规范化：显示名（`Claude Sonnet 5`）与未知带日期快照也能认出

⚠️ 这是**估算值**，与账单有小出入。精确对账用 Console 的 Cost 页面下载 CSV。
⛔️ Cost Admin API 那条路对本账号**不可用**（个人账号无法创建 Admin key），
   `cost_report.py` 已标注，除非哪天建了组织，否则不要再去追。
