# 素材管家 / 文档处理 / 微信指挥写代码 —— 接线说明

> 路线图第 4、8、9 件。这三件**不需要新写代码** —— Hermes 已有对应能力，
> 缺的只是把它们接到「提醒事项大脑」上。本文说明怎么接。
> 最后更新：2026-07-28

## 现成能力盘点（已在仓库里）

| 能力 | 位置 | 能干什么 |
|---|---|---|
| 语音转写 | `tools/transcription_tools.py` | 微信语音 → 文字 |

视觉与网页摘要这类副业不额外花主模型的钱，无需配置。

## 第 4 件：采访素材管家

**目标**：微信里发语音／照片／链接 → 自动转文字、归档到对应采访项目、生成摘要。

**接法**（写进 `reminders-brain` skill 的行为规则即可，无需新代码）：

1. 收到**语音** → `transcription_tools` 转写 → 判断是「待办」还是「素材」
   - 含时间地点、要执行 → 走建提醒流程
   - 只是记录、想法 → 追加到 `素材.md`，标注日期与来源
2. 收到**图片** → `vision_tools` 描述 → 同上判断
   - 若是名片／联系方式 → 补进 `联系人.md`
3. 收到**链接** → `web_extract` 摘要 → 存进 `素材.md`，附原链接
4. 每条素材记录格式：`日期 | 来源(语音/图片/链接) | 摘要 | 关联项目`

**归档到项目**：素材提到哪个项目名，就在 `项目跟踪.md` 对应行的「最近进展」
补一句，并刷新「上次更新」日期 —— 这样 `scan.py` 才不会误判为停滞。

## 第 9 件：文档 / 合同处理

**目标**：转发 PDF → 自动摘要 + 提取关键日期 → 关键日期自动变成提醒。

**接法**：

1. 收到 PDF → `ocr-and-documents` skill 提取文本
2. 让模型抽出：**合同双方 / 生效日 / 到期日 / 付款节点 / 违约条款**
3. 每个日期节点调一次：
   ```bash
   python3 提醒事项/sync.py add --title "<合同名> <节点名>" \
     --list "HERMES收件" --due "YYYY-MM-DD 09:00" \
     --notes "来源：<文件名>｜条款：<原文摘录>"
   ```
4. 摘要存 `素材.md`，原文件路径一并记录

⚠️ **合同含敏感信息** —— 摘要里不要抄录金额、身份证号、账号；只写节点与日期。

## 第 8 件：微信里直接指挥写代码

**目标**：手机上一句「修一下 X」→ 开会话干活 → 推分支 → 回结果。

**现状**：这就是 Hermes agent 本身的能力，微信网关（`gateway/platforms/weixin.py`）
已经把消息路由给 agent。**无需额外开发**，只需注意三点：

1. **仓库要在那台 Hermes 上 clone 好**，且分支权限配置正确。
2. **写操作要有确认门槛** —— 手机误触代价高。建议在该 agent 的规则里写明：
   「涉及 push / 删除 / 改配置的操作，先回报计划并等我确认。」
3. **长任务用异步**：手机端不适合盯着看，让它干完推送结果，而不是实时刷屏。

---

## 建议的推进顺序

1. 先把**第 4 件的语音那一条**跑通（你做采访，语音是最高频入口）
2. 再接**图片 → 联系人库**（名片、门牌号截图）
3. 文档处理（第 9 件）等真有合同要处理时再接
4. 第 8 件优先级最低 —— 手机写代码听着酷，实际用得少，且风险最高
