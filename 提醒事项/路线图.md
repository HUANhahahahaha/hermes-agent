## 🔥 第一梯队（收益最大，优先做）

### 🚫 供应商决策（2026-07-28 查证，两条早先建议已作废）

**① Anthropic 订阅 OAuth：绝对不要开 —— 已被官方封禁**
- 2026-01-09 起服务端拦截第三方客户端的订阅 OAuth；2026-02-19/20 法律条款
  明确写入禁止（Free/Pro/Max 的 OAuth 仅限 Claude Code 与 claude.ai）；
  2026-04-04 正式实施。OpenClaw / OpenCode / Cline / 官方 Agent SDK 均受影响。
- **Hermes 的实现正踩在禁区上**：它读取 `~/.claude/.credentials.json` 与
  macOS 钥匙串的 Claude Code 凭据（`agent/anthropic_adapter.py:857`），
  且该流程**没有任何警告**（Gemini 那条反而有）→ 仓库代码停留在政策更新前。
- **结论：维持 API key。** 早先「主力换订阅模式」的建议作废。
- 想用订阅价值，唯一合规路径是直接跑官方 Claude Code CLI 本身。

**② Gemini：用 API key，不要用订阅 OAuth**
- 仓库 `google-gemini-cli` OAuth 登录前会弹警告：Google 视其为违反政策，
  已有账号被限制（`hermes_cli/main.py:3842`）。
- 详见 `Gemini接入.md`（含配置步骤、模型选择、实测成本对比）。
- 实测结论：**Gemini 3.1 Pro（最强）月成本 $1.90，比 Haiku 4.5 的 $2.46 还便宜**，
  比现状 Sonnet 5 的 $7.38 省 74%。原因是缓存写单价差 7.5 倍。

### ⚠️ 缓存 TTL：结论已推翻，**维持 5m，不要改 1h**
早先建议改 `cache_ttl: "1h"`，用真实账单复算后**该建议是错的**：
- Anthropic 只有 5m / 1h 两档，**1h 即上限**，跨不过用户几小时~几天的间隔。
- 实测：写入折基准价 $6.00、读出折基准价 $11.50 → **平均每份缓存被读 1.92 次**，
  缓存是**净赚**的（不缓存 $17.89 → 现状 $9.04，省 $8.85）。
- 改 1h 后写入premium 从 1.25x 涨到 2x，光写入 $12.00 就超过现全部账单 →
  **反而贵 $4.50**。
- 早先「83% 是浪费」的说法也不成立：83% 只是缓存写的占比，不等于浪费。
- 真正省钱杠杆：①订阅模式 ②精简每次重传的 prompt ③杂活分流便宜模型。
